## Features

- **Audio Classification**: Real-time speech disorder detection
- **Confidence Scores**: Detailed classification metrics
- **Feature Analysis**: Audio processing visualization
- **Performance Metrics**: Model accuracy statistics
- **Cloud Model**: Automatic download from Google Drive

## Model Information

- **Architecture**: Neural Network (1.3M parameters)
- **Classes**: 4 (Apraxia, Dysarthria, Dysphonia, Healthy)
- **Training Accuracy**: 93.5%
- **Validation Accuracy**: 75.1%
- **Dataset**: 2,550 samples (2,000 real + 550 synthetic)

## Supported Formats

- WAV, MP3, M4A, OGG
- Max duration: 10 seconds
- Sample rate: 16kHz
- Processing: Real-time
